# Fuel Sense ⛽

A fuel log that turns refills into charts: efficiency, cost and refill patterns.

## What it shows

- **Smart suggestions** based on your refill history
- **km/L over time**: how fuel efficiency changes
- **Fuel cost per fill**
- **₹ spent vs km gained**
- **Refill frequency**

## Quick start

1. Download `index.html`, `app.js`, `parser.js` and `styles.css`.
2. Open `index.html` in any modern browser.

No server, install or sign-up is needed.

## Files

- `index.html`: page structure
- `app.js`: charts and app logic
- `parser.js`: reads refill data
- `styles.css`: styling
